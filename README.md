# ZARA × Victoria's Secret — Евпатория

Интернет-магазин на чистом HTML/CSS/JS, без сборки и сервера. Откройте `index.html` или выложите папку на любой хостинг (GitHub Pages, Netlify).

## Что редактировать
- `js/config.js`: адрес, часы работы, телефон, WhatsApp/Telegram для заказов, стоимость доставки.
- `js/products.js`: товары и разделы. Чтобы показать настоящее фото, добавьте товару `img: "images/файл.jpg"`.

## Как работает заказ
Корзина и избранное хранятся в браузере покупателя. После оформления заказа открывается готовый текст заказа, который покупатель одним нажатием отправляет в WhatsApp/Telegram магазина или звонит.
