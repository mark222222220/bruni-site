# AVP system — приложение для айфона

Пульт руководителя завода стеклопакетов «Гласс-Хаус Крым»: заказы и этапы производства, склад с заявкой поставщику, маржа по клиентам, платёжный календарь и чаты команды. Оформление Liquid Glass: на iOS 26 настоящие стеклянные панели и системная панель вкладок, на старых iOS и Android — размытие.

Написано на Expo (SDK 58), React Native и Expo Router.

## Что умеет версия 0.4

| Раздел | Что внутри |
|---|---|
| Главная | Деньги на счёте и платежи, средняя маржа, отгрузки на завтра, быстрые действия, воронка производства, сигналы с кнопкой «Обсудить» |
| Заказы | Поиск, фильтры, этапы «Принят → Раскрой → Сборка → Готов → Отгружен», создание заказа, просроченные подсвечиваются |
| Склад | Остатки с кнопками ±, минимумы, автоматическая заявка с округлением до упаковки, отправка заявки в чат |
| Маржа | Плавный ползунок порога, клиенты с долей оборота, добавление и правка клиентов |
| Деньги | Платежи, отметка оплаты, добавление платежа, проверка «хватает ли» |
| Чаты | Каналы «Общий», «Заказы», «Склад», «Деньги», цитаты, счётчики непрочитанных |
| Настройки | 5 тем (как в системе, стекло тёмное/светлое, графит, светлая), 4 цвета акцента, крупный текст, вибрация, порог маржи, имя и роль |

Роли: руководитель, кладовщица, менеджер, бухгалтер — у каждой свои вкладки.

## Два режима данных

- **Демо** (по умолчанию): данные хранятся только на телефоне, есть примерные заказы, клиенты и склад.
- **Облако** (Supabase): вся команда видит изменения сразу. Включается, когда в `.env` прописаны адрес и ключ проекта.

## Как запустить на своём айфоне

Нужен компьютер (Mac или Windows) с Node.js 20+.

```bash
cd avp-app
npm install
npx expo start
```

Откройте камеру айфона и наведите на QR-код в терминале. Приложение откроется в **Expo Go** (бесплатное приложение из App Store). Системная стеклянная панель вкладок и Liquid Glass требуют отдельной сборки — см. ниже; в Expo Go часть эффектов может выглядеть проще.

## Как подключить облачную базу (для работы командой)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (бесплатный тариф подойдёт).
2. Откройте **SQL Editor**, вставьте содержимое файла `supabase/schema.sql` и нажмите **Run**.
3. **Authentication → Sign In / Providers** → включите **Anonymous sign-ins**.
4. **Project Settings → API**: скопируйте `Project URL` и `anon public` ключ.
5. Скопируйте `.env.example` в `.env` и вставьте туда эти два значения.
6. Перезапустите `npx expo start`.

> Сейчас доступ открыт всем, у кого установлено приложение: это тестовый режим. Перед рабочим запуском нужно сделать вход по приглашению и права по ролям — это следующий этап.

## Как собрать приложение и поставить в App Store

Нужны: аккаунт [Apple Developer](https://developer.apple.com/programs/) (99 $ в год) и бесплатный аккаунт [Expo](https://expo.dev). Mac не нужен — сборка идёт в облаке EAS.

```bash
npx eas-cli@latest login
npx eas-cli@latest build:configure
# тестовая сборка для своих айфонов (установка по ссылке):
npx eas-cli@latest build --platform ios --profile preview
# сборка для App Store:
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios
```

EAS попросит войти в Apple ID и сам создаст сертификаты. После `submit` сборка появится в App Store Connect → TestFlight: туда можно пригласить сотрудников по почте до публикации.

Перед публикацией поменяйте `ios.bundleIdentifier` в `app.json`, если `ru.glasshouse.avp` занят.
