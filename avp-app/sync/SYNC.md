# Ночная синхронизация: таблица завода → закрытая база

Каждую ночь в 00:00 (Москва) запускается задача:

1. Читает листы таблицы «Пульт руководителя — Гласс-Хаус Крым»
   (`1Q300QHMwsfH-KmvsmfWPob-4Vgm3vwK-ZbesRhJnfko`) и кладёт ответы как есть в `sync/raw/`:

   | файл | диапазон |
   |---|---|
   | `main.json` | `'Главный'!A1:AD40` |
   | `app.json` | `'Для приложения'!A1:G30` |
   | `stock.json` | `'Склад для приложения'!A1:O150` |
   | `clients.json` | `'Клиенты по месяцам'!A1:M60` |
   | `payments.json` | `'Платёжный календарь'!A1:F80` |
   | `shipments.json` | `'Отгрузки'!A1:J300` |
   | `bank.json` | `'Банк — остатки'!A1:J40` |

2. `node scripts/build-snapshot.mjs` — собирает `src/data/sheets.json`.
3. `node scripts/push-snapshot.mjs` — загружает разделы в таблицу `factory_snapshot` (ключ подставляет прокси окружения).

Приложение получает новые цифры при следующем открытии. `sync/raw/` и `src/data/sheets.json` в git не хранятся.
